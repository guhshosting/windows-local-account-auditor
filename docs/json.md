# JSON contract and time semantics

> Release preparation update (2026-10-05): see [current executable qualification and package provenance](../RELEASE-QUALIFICATION.md). Historical validation and pending-test statements in this document describe the original development snapshot. The final ZIP is assembled after qualification and has not been run on Windows.


`docs/schema.json` is a JSON Schema Draft 7 contract. The root has schema_version, acquisition, view, users, groups, machine_policy, findings, unavailable_information and warnings. All map keys and arrays are deterministic for the same snapshot: users/groups sort by UTF-8 name bytes, members by SID string, memberships by group name, findings by code/subject/evidence, failures by source/subject/error. Live timestamps and password age naturally vary. Ordering is locale-independent, not numeric SID ordering. No whitespace or key ordering is semantically required by consumers.

Every metadata/account/policy field is a `{ "status": ..., "value": ... }` object. `available` carries a typed string, integer or boolean; all other statuses carry JSON null. False is an available boolean, distinct from unknown/unavailable. Empty descriptions are available empty strings; NULL descriptions are absent. `absent` means the source explicitly has no value; `unavailable` means information was not obtained or intentionally not resolved; `inaccessible` means access denied; `unknown` means exposed sentinel/no determination; `not_applicable` means the value has no meaning in that configuration; `never` and `unlimited` explicitly preserve time sentinels. Omitted sections in filtered views use empty arrays/maps and the root view explains why; omission is not evidence of a successfully acquired empty inventory.

User fields: sid (string), rid (integer), built_in (Administrator/Guest/DefaultAccount/WDAGUtilityAccount/ordinary), enabled, password_required, password_never_expires, user_may_change_password, password_expired, locked_out (booleans), flags (unsigned integer bitmask), description (string), account_expires, last_logon (Unix seconds), password_age_seconds, bad_password_count and logon_count (integers), membership_status (complete_direct_evidence/partial_direct_evidence). local_groups contains directly observed SID-matched group names, not effective/transitive membership. A partial membership status must be considered before treating an empty array as absence.

Group fields: sid, description, recognized_builtin, privileged_classification, membership_status (complete or inaccessible/unavailable). Root group privileged repeats the classification as a status-bearing value. Unknown custom groups never become false. Member sid preserves the API SID string, name contains locally matched name or unavailable, kind is local_user/local_group/unresolved. An unresolved member can be external, deleted, well-known, or simply outside our acquired inventory; no classification of domain ownership is implied. An invalid SID yields an empty string and an acquisition issue instead of an invented identity.

Machine policy fields: minimum_password_length, maximum_password_age_seconds, minimum_password_age_seconds, password_history_length, lockout_threshold, lockout_duration_seconds, lockout_observation_window_seconds. Metadata contains application_version, scope, read_only, domain_controller, collected_at_unix_seconds, user_count, group_count, acquisition_error_count.

Time rules: NetAPI account timestamps are unsigned seconds since 1970-01-01 00:00:00 UTC, not FILETIME. TIMEQ_FOREVER (0xFFFFFFFF) account expiration is never. Zero last logon is unknown; no epoch date is invented. Zero account expiration is preserved as the configured epoch timestamp because zero is not the documented never sentinel. Last-logon 0xFFFFFFFF is conservatively unknown. Duration 0xFFFFFFFF is unlimited; zero duration is preserved as zero, including lockout until administrative unlock. When lockout_threshold is zero, lockout duration and observation window are not_applicable. Counter 0xFFFFFFFF is unknown and counter zero is available zero. Password age 0xFFFFFFFF is conservatively unknown. Password age is elapsed seconds, not a password-change timestamp. The collector's FILETIME is converted separately to 64-bit Unix seconds. No inferred dates are emitted.

Findings have stable code, subject, evidence strings. unavailable_information lists operational source failures and Win32 error codes. Known scope limitations are also represented in field statuses and warnings, and unresolved member findings. Fatal failures are written to stderr without a JSON document. A filtered report retains machine-wide findings; --user retains the selected user's findings and machine findings. Complete audit acquisition is performed regardless of selected view.
